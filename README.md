## 🛡️ Windows SmartScreen Warning

  

  

When you first launch the application, Windows SmartScreen may show a security warning because the application is not digitally signed. This is normal for unsigned applications.

  

  

**For personal use (free):**

  

- On first launch: Click **"More info"** → **"Run anyway"**

  

- Windows will remember your choice for this file

  

- Or add the file/folder to Windows Defender exclusions:

  

- Go to **Windows Settings** → **Privacy & Security** → **Windows Security** → **Virus & threat protection**

  

- Click **"Manage settings"** under Virus & threat protection settings

  

- Scroll down to **"Exclusions"** and click **"Add or remove exclusions"**

  

- Click **"Add an exclusion"** → **"File"** or **"Folder"**

  

- Select the downloaded `.exe` file or the folder containing it

  

  

>  **Note:** The "Unknown publisher" warning appears because the application is not digitally signed. To completely remove this warning, a code signing certificate from a trusted Certificate Authority (CA) is required, which costs approximately $200+ per year.
